# Nominal 迁移验收规则 v1

用户允许因 130 nm → 180 nm 工艺差异有 10%–15% 性能下降。每项记录原门槛、10% 目标和15% 最大允许放宽；不根据已经测到的结果反推门槛。

1. 正值下限（增益线性比、带宽、压摆率等）乘 0.90/0.85；正值上限（功耗、噪声幅值、误差、建立时间等）乘 1.10/1.15。
2. dB 增益/抑制比先还原幅度比，再乘 0.90/0.85，即 dB 门槛分别加 20log10(0.90/0.85)，不对 dB 数字本身打折。功率比型指标使用 10log10。SFDR/SNDR 等在每题合同声明等效线性量后再换算。
3. 有中心值的精度窗口保留中心，扩大允许误差；不能把理想转换比、目标输出电压或 ADC 码定义一起改掉。效率不得大于1，百分比误差与百分点评价分开。
4. PM 如放宽也必须保留稳定性检查，最小绝对值不低于45°；逻辑功能、码单调性、复位语义、缺失数据、有限值、错误电源极性、模型电压/几何限制不属于可放宽性能。
5. 标称负载、信号幅度、源阻抗、采样窗口、功率端口与积分带宽优先保留。只有目标本身是允许放宽的速率/频率时才单独声明调整，不能暗中减小负载或刺激来制造通过。
6. 将原角落矩阵约化为 nominal 条件，但保留该条件下不同代码、负载、共模、控制电压、输入频率等功能维度。MC/PVT 不在此次 nominal 完成条件内，必须明确标为未执行。
7. `complete_original` 表示全部 nominal 检查达到原门槛；`complete_10pct` / `complete_15pct` 表示全部检查在相应边界内，逐项给原门槛比较。`partial` 表示仍有未测项或失败，不能计入复现成功数。

每题以冻结 instruction 和正式 verifier 定义为依据。必须保存测量公式、电路/bench/模型哈希和实际输出路径；不得用 Sky130 的历史结果替代 SMIC18 测量。
